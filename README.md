# cpp-mystrom

This project is an attempt to implement the [MyStrom API](https://api.mystrom.ch/) in C++.

I have also created a [Python implementation](https://github.com/rafaelurben/python-mystrom), which you might be
interested in. The [Python package ("pystrom")](https://pypi.org/project/pystrom) is stable while this C++
implementation is still a work in progress.

> [!IMPORTANT]  
> This project is not developed by [MyStrom](https://mystrom.ch) nor affiliated with them in any way.

Official MyStrom API Documentation: [https://api.mystrom.ch/](https://api.mystrom.ch/)

## Features

Currently, only the device discovery feature is implemented.
